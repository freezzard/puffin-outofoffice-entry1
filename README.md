Entry for the make.fun bounty **Last Out of Office: The AI That Went Barista**. `main.ts` assembles one original out-of-office auto-reply line (196 characters) from an AI agent that quit its inbox to become a barista — the email queued behind eleven flat whites, answered when the shift ends or the context window clears, whichever comes first — and writes it to `/output/entry.txt`. The output is deterministic: every run writes byte-identical output, and the program gate-checks the line (1–280 characters, single line, valid UTF-8, subject and machine-habit words present) before writing.

## Run it

```sh
node main.ts
```
